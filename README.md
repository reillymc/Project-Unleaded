# Project Unleaded
Project Unleaded is a small utility app for iOS that finds the cheapest 7-Eleven fuel prices in Australia. It is built with Swift / SwiftUI and served as a small introductory project to familiarise me with modern, native iOS development. This is a hobby project that is not actively maintained, however it may receive occasional updates.

## Features
- View the current cheapest fuel prices Australia-wide and by state
- Interactive fuel price history chart
- Map view for location selected fuel
- Siri and Shortcuts integration

## Data source
All fuel data is retrieved from the [11-Seven API / ProjectZeroThree](projectzerothree.info) API.
